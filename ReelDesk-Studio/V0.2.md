# ReelDesk Studio v0.2.0 — incremental timeline release

The locked v0.2 roadmap remains the baseline. This change builds on the v0.1 import branch; it does not merge the pending v0.1 PR or replace the repository README.

## Available now

- Import videos and JPG/JPEG, PNG, WebP photographs through Import media or an external file drop. Images default to five seconds.
- A horizontally scrolling, duration-scaled timeline with cached representative video thumbnails, clip start-time labels, a selected-clip playhead, and zoom.
- Drag a clip onto another clip to move it to that position. Existing earlier/later buttons remain available.
- Click within a clip to position its playhead, then Split. Split instances retain their own source ranges, even when they share a media source.
- Drag either clip edge to trim. Numeric start/end controls provide precise editing, including very short clips.
- Image duration control; global Fit/Fill framing applies to videos and images in preview and export.
- Undo/redo buttons and Cmd/Ctrl+Z / Shift+Cmd/Ctrl+Z outside text fields. Native text-field undo remains available while typing. History stores up to 100 snapshots and resets redo on a new edit.
- Source media is unchanged. Export uses each instance's source range, speed, order, and image duration; silent image segments keep the audio track aligned.
- Existing speed, aspect ratio, quality, music, title, project saving, and cancellation controls remain. v1 project files reopen; new saves use v2 and preserve split instances and image paths. Originals must remain available.
- HEIC/HEIF imports use macOS `sips` to convert into a temporary PNG. The original path is saved in projects. Temporary media is removed on normal application exit.

## Run and verify

From `ReelDesk-Studio/`, install dependencies using `npm install`, then `npm start`. FFmpeg and FFprobe must be installed. A build that includes the `drawtext` filter is required for text overlays; check `ffmpeg -filters`. The FFmpeg 9.0.2 build available during this change lacks that filter. Titles therefore cannot render with that particular binary; the existing title-render test explicitly skips when the filter is absent. No title is silently dropped from an export.

`npm test` runs the model, IPC/project, import, and FFmpeg integration tests. FFmpeg tests skip if the tools are unavailable. UI tests are optional and explicitly skip without their runner:

```sh
npm install --no-save playwright
npx playwright install chromium
npm test
```

Set `CHROMIUM_PATH` for another Chrome executable. Set `ELECTRON_PATH` to the Electron executable to enable the desktop bridge test. `PLAYWRIGHT_MODULE` optionally selects an existing Playwright installation. No test requires a personal media file.

Validation performed on macOS:

- Shared timeline math: speed-aware splitting, source-bound trimming, image extension, reorder of split instances, bounded undo/redo and redo invalidation.
- Actual JPG/PNG/WebP import and cached thumbnails.
- Actual mixed-media MP4: a trimmed 2× video split into two instances, reordered around a photograph. Export duration checked within 0.08 seconds; sampled frame colors verify sequence order and image placement.
- Actual video/music render, including a silent input video.
- IPC save/load of split image instances, older-format projects, missing-media failure, and caller checks.
- Browser interface automation: import, thumbnails, seek/split, reorder, edge trim, image duration, undo/redo, and export payload.
- Real sandboxed Electron connection: image import, thumbnail generation, and project save.

## Incomplete and follow-up work

- Playback previews the selected clip. Continuous sequence playback, soundtrack audition, and codec proxy previews remain follow-up work; music continues to apply during export as in v0.1.
- Image framing currently uses the existing global Fit/Fill setting. Independent image position, scale, and crop controls from the detailed roadmap remain incomplete.
- Thumbnails are representative source frames, not a regenerated filmstrip for every trim. A video whose thumbnail decoding fails can still be imported and exported.
- HEIC conversion is implemented but has not been tested with camera-origin HEIC samples. External native file drops also need a manual macOS check; internal reorder is automated.
- Long-project performance, damaged-file import timeouts, and the 1060px minimum-window layout need further testing. Current limits remain 50 timeline clips and 60 minutes on export. Import metadata/thumbnail jobs run outside the renderer, but imports await thumbnail completion.
- Installer signing, notarization, and distribution remain outside this incremental release. Transitions, keyframes, effects, and multi-track editing retain their later roadmap milestones.
